# v0001：概念基线

状态：Draft

## 本轮目标

建立天机阁第一版概念骨架，明确：

- 仙人、皇帝、三省、六部和百官的技术映射；
- 人类主权与 Agent 权限边界；
- 高级 Agent 与确定性工具的分工；
- 单租户朝廷如何扩展成多租户平台；
- AgentOS 与天机阁业务系统的边界；
- 原始资料、证据、主张、事实和研判的基本关系。

## 当前输入

- 最初的天机阁总体架构设想；
- 三省六部作为 Agent 治理体系的类比；
- Windows 进程与操作系统作为多 Agent 运行模型的类比；
- “仙人—皇帝—朝廷”的人机关系；
- 多仙门、多仙人和租户级逻辑朝廷；
- 少数高级官员使用 Agent，其余尽可能采用脚本、工具、Worker 和规则。
- 架构讨论采用对话驱动的持续沉淀机制：有价值的新见解必须在产生当轮归档，并保持思路、迭代、决策和当前架构之间的成熟度边界。
- 候选设计方法采用“全域骨架先行，局部深度迭代”：不从 MVP 扩建终局，而是先定义完整问题空间，再逐步提高各区域的设计分辨率。
