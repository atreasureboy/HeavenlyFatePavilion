# 阶段 1：整体骨架扩展与完善计划

状态：Accepted

记录日期：2026-07-24

## 一、阶段修正

`Skeleton v0.1` 完成的是第一轮内部闭合：

- 已有一级面能够相互连接；
- 对象、契约、状态、横切维度和场景没有明显断链；
- 当前已知问题基本能够找到归属。

它不意味着整体骨架阶段结束。当前仍处于：

```text
扩大骨架
→ 从更多宏观视角扫描整个问题空间

完善骨架
→ 补齐缺失的一级关系、全局视图和结构不变量

反复闭合
→ 每增加一圈结构，就重新检查对象、契约、状态、横切与场景
```

在整体骨架达到稳定终局基线前，不进入单个数据库、协议字段、算法参数、部署节点或官署内部流程的详细设计。

## 二、为什么 v0.1 闭合仍然不够

当前七道完整性门验证的是“已有骨架内部是否自洽”，还没有充分证明“整个问题空间是否已经被看见”。

```text
内部闭合问题：
已有节点之间能否连起来？

外部完备问题：
是否还存在整片没有画进来的结构区域？
```

因此，后续重点不是把某个节点写得更厚，而是继续从更高层视角寻找：

- 缺失的参与者；
- 缺失的运行形态；
- 缺失的全局流；
- 缺失的权力关系；
- 缺失的规模和时空维度；
- 缺失的系统外部关系；
- 缺失的演进与失效边界。

## 三、骨架扩展的七个扫描面

### S1：问题空间与能力边界

检查天机阁所有宏观能力是否都能挂入十面，是否存在需要新增一级面或重划边界的稳定问题族。

只讨论能力类别和所有权，不深入实现。

### S2：主体、生态与主权边界

从仙人、租户、平台、外部协作者、数据所有者、模型/Tool 供应者、监管者、被研究对象和外部行动系统等角度，检查主体是否完整。

只确定关系和权力来源，不展开角色权限表。

### S3：全局流与多种运行形态

除当前调查主链外，检查：

- 交互式请求；
- 事件驱动响应；
- 持续监测；
- 周期批处理；
- 人类协作与长期案件；
- 自主演进；
- 外部行动和补偿；
- 灾难与恢复。

只画全局流和分叉，不定义消息协议。

### S4：控制、数据、知识与反馈分流

分别建立：

```text
控制流
数据流
知识形成流
决定与授权流
预算与资源流
审计与证据流
反馈与演进流
```

防止当前同一张总图用一条箭头混写多种语义。

### S5：空间、时间与规模骨架

检查骨架是否能表达：

- 单用户、单租户、多租户和联合空间；
- 单次任务、长期 Mission 和跨年知识演化；
- 本地、区域、多区域和全球数据边界；
- 小规模查询、热点事件和超大规模持续监测；
- 当前模型能力与未来超级模型能力。

只确定尺度维度和结构变化点，不做容量数字与部署拓扑。

### S6：非功能与生存性骨架

把可靠性、安全、隐私、合规、一致性、可恢复性、可解释性、可停止性和人类主权作为宏观结构检查，而不是留到实现阶段才添加。

只定义质量属性所在位置、全局责任和不可接受失败，不计算 SLO。

### S7：负空间、反架构与未来替换

检查：

- 哪些东西明确不属于某个面；
- 哪些组合会产生权力集中、数据污染或 Agent 失控；
- 哪些结构只因当前模型能力而存在；
- 超级模型出现后哪些节点可以合并、哪些制衡仍不能取消；
- 哪些外部能力不能被默认信任。

只确定可替换边界和反例，不设计具体替换方案。

## 四、骨架迭代轮次

```text
Skeleton v0.1：第一轮内部闭合
    已完成十面、对象、契约、状态、横切和基础场景

Skeleton v0.2：广度扩展
    用 S1～S7 扫描缺失结构，允许调整十面及二级能力

Skeleton v0.3：全局视图闭合
    补齐不同流、运行形态、主体生态、时空尺度和生存性视图

Skeleton v0.x：反复压力测试
    用反例、未来能力、极端规模和失效场景继续查漏

Skeleton v1.0：整体骨架基线
    才允许将主要精力转入局部专题深度设计
```

版本号表达骨架成熟度，不对应软件发布，也不表示会实现系统。

## 五、骨架 v1.0 完成门槛

只有同时满足下列条件，整体骨架阶段才结束：

1. 任何新宏观问题都能稳定归入现有一级面、横切维度或外部边界；
2. 从业务、数据、Agent、治理、多租户、生态、规模、时间、可靠性和未来演进视角扫描后，没有整片结构空白；
3. 控制、数据、知识、授权、预算、审计和反馈流能够分别阅读；
4. 交互、监测、批处理、协作、演进、外部行动和灾难恢复均有顶层位置；
5. 当前能力与未来能力的可替换边界明确；
6. 关键权力集中、循环依赖和单点认知风险已经在骨架层暴露；
7. 新增结构经过对象、契约、状态、横切和场景再次闭合；
8. 至少连续两轮宏观扫描只增加二级节点或视图，不再改变一级骨架。

## 六、当前下一步

当前正在执行 `Skeleton v0.2` 的第一轮全域盲区扫描，不选择“数据库架构”或“Agent 运行时”深入。

推荐顺序：

```text
主体与外部生态【完成第一版】
→ 多种运行形态
→ 七类全局流分离
→ 时空与规模维度
→ 非功能与生存性
→ 未来能力和负空间
→ 重新评估十面与七道完整性门
```

### S2 第一版扫描结果

主体与外部生态扫描已经补入：

- 需求者、产品消费者、行动责任人不再合并成单一“用户”；
- 权利人、数据主体、被研究主体和受影响第三方；
- 法律、监管、司法、标准和独立监督主体；
- 开发者、能力市场、开源依赖、同行系统与联合联盟；
- 不经正式接口也能影响系统的对抗主体；
- 人类目标、平台、租户、数据、事实、产品和外部行动的分域主权；
- 内部 Agent 权力派生、限域、限时和可撤销原则。

第一版扫描没有新增一级逻辑面。这些主体通过系统边界、横切治理和现有十面发生关系，说明当前十面暂时能够容纳该轮扩展。
