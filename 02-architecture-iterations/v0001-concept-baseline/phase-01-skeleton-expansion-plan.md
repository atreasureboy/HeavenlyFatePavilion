# 阶段 1：整体骨架扩展与完善计划

状态：Accepted

记录日期：2026-07-24

## 一、阶段修正

`Skeleton v0.1` 完成的是第一轮内部闭合：

- 已有一级面能够相互连接；
- 对象、契约、状态、横切维度和场景没有明显断链；
- 当前已知问题基本能够找到归属。

它不意味着整体骨架阶段结束。当前仍处于：

```text
扩大骨架
→ 从更多宏观视角扫描整个问题空间

完善骨架
→ 补齐缺失的一级关系、全局视图和结构不变量

反复闭合
→ 每增加一圈结构，就重新检查对象、契约、状态、横切与场景
```

在整体骨架达到稳定终局基线前，不进入单个数据库、协议字段、算法参数、部署节点或官署内部流程的详细设计。

## 二、为什么 v0.1 闭合仍然不够

当前七道完整性门验证的是“已有骨架内部是否自洽”，还没有充分证明“整个问题空间是否已经被看见”。

```text
内部闭合问题：
已有节点之间能否连起来？

外部完备问题：
是否还存在整片没有画进来的结构区域？
```

因此，后续重点不是把某个节点写得更厚，而是继续从更高层视角寻找：

- 缺失的参与者；
- 缺失的运行形态；
- 缺失的全局流；
- 缺失的权力关系；
- 缺失的规模和时空维度；
- 缺失的系统外部关系；
- 缺失的演进与失效边界。

## 三、骨架扩展的七个扫描面

### S1：问题空间与能力边界

检查天机阁所有宏观能力是否都能挂入十面，是否存在需要新增一级面或重划边界的稳定问题族。

只讨论能力类别和所有权，不深入实现。

### S2：主体、生态与主权边界

从仙人、租户、平台、外部协作者、数据所有者、模型/Tool 供应者、监管者、被研究对象和外部行动系统等角度，检查主体是否完整。

只确定关系和权力来源，不展开角色权限表。

### S3：全局流与多种运行形态

除当前调查主链外，检查：

- 交互式请求；
- 事件驱动响应；
- 持续监测；
- 周期批处理；
- 人类协作与长期案件；
- 自主演进；
- 外部行动和补偿；
- 灾难与恢复。

只画全局流和分叉，不定义消息协议。

### S4：控制、数据、知识与反馈分流

分别建立：

```text
控制流
数据流
知识形成流
决定与授权流
预算与资源流
审计与证据流
反馈与演进流
```

防止当前同一张总图用一条箭头混写多种语义。

### S5：空间、时间与规模骨架

检查骨架是否能表达：

- 单用户、单租户、多租户和联合空间；
- 单次任务、长期 Mission 和跨年知识演化；
- 本地、区域、多区域和全球数据边界；
- 小规模查询、热点事件和超大规模持续监测；
- 当前模型能力与未来超级模型能力。

只确定尺度维度和结构变化点，不做容量数字与部署拓扑。

### S6：非功能与生存性骨架

把可靠性、安全、隐私、合规、一致性、可恢复性、可解释性、可停止性和人类主权作为宏观结构检查，而不是留到实现阶段才添加。

只定义质量属性所在位置、全局责任和不可接受失败，不计算 SLO。

### S7：负空间、反架构与未来替换

检查：

- 哪些东西明确不属于某个面；
- 哪些组合会产生权力集中、数据污染或 Agent 失控；
- 哪些结构只因当前模型能力而存在；
- 超级模型出现后哪些节点可以合并、哪些制衡仍不能取消；
- 哪些外部能力不能被默认信任。

只确定可替换边界和反例，不设计具体替换方案。

## 四、骨架迭代轮次

```text
Skeleton v0.1：第一轮内部闭合
    已完成十面、对象、契约、状态、横切和基础场景

Skeleton v0.2：广度扩展
    用 S1～S7 扫描缺失结构，允许调整十面及二级能力

Skeleton v0.3：全局视图闭合
    补齐不同流、运行形态、主体生态、时空尺度和生存性视图

Skeleton v0.x：反复压力测试
    用反例、未来能力、极端规模和失效场景继续查漏

Skeleton v1.0：整体骨架基线
    才允许将主要精力转入局部专题深度设计
```

版本号表达骨架成熟度，不对应软件发布，也不表示会实现系统。

## 五、骨架 v1.0 完成门槛

只有同时满足下列条件，整体骨架阶段才结束：

1. 任何新宏观问题都能稳定归入现有一级面、横切维度或外部边界；
2. 从业务、数据、Agent、治理、多租户、生态、规模、时间、可靠性和未来演进视角扫描后，没有整片结构空白；
3. 控制、数据、知识、授权、预算、审计和反馈流能够分别阅读；
4. 交互、监测、批处理、协作、演进、外部行动和灾难恢复均有顶层位置；
5. 当前能力与未来能力的可替换边界明确；
6. 关键权力集中、循环依赖和单点认知风险已经在骨架层暴露；
7. 新增结构经过对象、契约、状态、横切和场景再次闭合；
8. 至少连续两轮宏观扫描只增加二级节点或视图，不再改变一级骨架。

## 六、当前下一步

`Skeleton v0.2` 的全域盲区扫描与集中复核已经完成，不选择“数据库架构”或“Agent 运行时”深入。

推荐顺序：

```text
主体与外部生态【完成第一版】
→ 多种运行形态【完成第一版】
→ 七类全局流分离【完成第一版】
→ 时空与规模维度【完成第一版】
→ 非功能与生存性【完成第一版】
→ 未来能力和负空间【完成第一版】
→ 重新评估十面与七道完整性门【完成】
```

### S2 第一版扫描结果

主体与外部生态扫描已经补入：

- 需求者、产品消费者、行动责任人不再合并成单一“用户”；
- 权利人、数据主体、被研究主体和受影响第三方；
- 法律、监管、司法、标准和独立监督主体；
- 开发者、能力市场、开源依赖、同行系统与联合联盟；
- 不经正式接口也能影响系统的对抗主体；
- 人类目标、平台、租户、数据、事实、产品和外部行动的分域主权；
- 内部 Agent 权力派生、限域、限时和可撤销原则。

第一版扫描没有新增一级逻辑面。这些主体通过系统边界、横切治理和现有十面发生关系，说明当前十面暂时能够容纳该轮扩展。

### S3 第一版扫描结果

全局运行形态扫描已经建立：

- 即时交互与快速查询；
- 复杂调查与案件；
- 持续监测与守望；
- 事件驱动响应；
- 周期批处理、回填与重建；
- 多人、多 Agent 与跨租户协作；
- 主动情报与订阅交付；
- 能力观察、实验与演进；
- 受控外部行动与补偿；
- 事故、降级与灾难恢复。

同时提出 `Mandate → Mission → Run → Task/Agent/Tool → Product/Effect` 候选层级，用于骨架上区分长期目标与临时执行。Mandate、Trigger、Incident 和 Action 是否成为独立对象及其状态，明确推迟到骨架稳定后的专题设计。

十种形态均能映射到现有十面，暂未形成新增一级面的证据。

### S4 第一版扫描结果

已经把此前总图中的混合箭头拆成七条全局流：

- 控制流；
- 数据流；
- 知识形成流；
- 决定与授权流；
- 预算与资源流；
- 审计与证据流；
- 反馈与演进流。

本轮确认：同一任务会同时穿过七条流，但控制权、数据所有权、事实接受权、资源权和审计权不能因共用一次调用而合并。

七条流均能由现有十面共同承载，未发现新增一级面的必要。该轮完成后进入 `S5：空间、时间与规模骨架`。

### S5 第一版扫描结果

已经把此前散落的租户、区域、长期知识和规模概念整理成四条正交扩展轴：

- 作用域轴：共享平台、租户逻辑朝廷、联合空间、用户工作空间与 Mission / Run；
- 辖域轴：本地、区域、跨区域与全球信息环境；
- 时间轴：瞬时交互、执行时段、长期 Mission、持续守望、跨年知识与能力代际；
- 规模轴：单点查询、租户负载、热点事件与全域持续感知。

同时确认模型能力代际是作用于全架构的变化变量，而不是新增业务空间。模型变强可以移动 Agent / Tool 边界、合并部分执行角色，但不能自动取消人类主权、三权可区分性、租户与辖域边界、证据语义分层、审计、纠正和可停止性。

本轮补入辖域覆盖、区域自治和外部联邦三类宏观边界，但它们属于横切约束与承载关系，不构成新增一级逻辑面。该轮完成后进入 `S6：非功能与生存性骨架`。

### S6 第一版扫描结果

已经把质量属性整理成四类系统完整性：

- 主权与合法性完整性；
- 认识与语义完整性；
- 运行与连续性完整性；
- 演进与时代完整性。

本轮建立了由人类控制入口、身份权力与政策根、隔离与紧急控制、权威状态与证据根、真实运行态势、恢复与纠正协调共同组成的“最低生存内核”。它是多个现有面共同承担的逻辑能力集合，不是新的平台、组件或一级面。

同时建立 `预防 → 感知 → 遏制 → 延续 → 恢复 → 纠正与演进` 六阶段防线，明确主体、任务、租户、知识、能力、供应、区域和平台八类失效域，并区分可以降低的服务能力与绝不能降低的主权、权限、证据、审计和人类停止底线。

本轮没有发现新增一级逻辑面的必要。该轮完成后进入 `S7：负空间、反架构与未来替换`。

### S7 第一版扫描结果

已经为十个一级面补齐负职责边界，并确认四类负空间：

- 职责负空间；
- 权力负空间；
- 语义负空间；
- 信任负空间。

本轮明确禁止自证闭环、智能即权力、执行即授权、存储即真理、平台即租户和演进即自我授权六类权力组合，并将万能皇帝、三省机械 Prompt、所有官署 Agent 化、聊天记录即状态、单库共享、向量检索即事实库、安全 Agent 单点和演进直接上线等列为典型反架构。

未来模型可以减少 Agent 数量、合并组织实例、改变 Agent / Tool 分工和替换技术外壳；但人类主权、三权可区分性、对象语义、作用域、契约、证据、血缘、审计、纠正与演进纪律不会因模型智商提升而自动消失。

S7 没有发现新增一级逻辑面的必要。S2～S7 第一版广度扫描至此完成；该轮结束后转入十面、七道完整性门和 `Skeleton v0.2` 新增结构的集中复核。

### Skeleton v0.2 集中复核结果

集中复核裁定：

- 十个一级逻辑面保留，不增、不减、不重划；
- 主体生态属于外部边界，运行形态属于十面组合，七流属于跨面关系；
- 时空规模属于坐标轴，生存内核属于跨面能力组合，负空间属于禁止边界；
- 安全、隐私、合规、联邦、外部行动和超级模型均没有形成独立一级职责面的证据；
- 七道完整性门达到骨架级闭合，G7 保留八个宏观压力场景进入下一轮。

`Skeleton v0.2` 因此完成第二轮宏观闭合。下一步进入 `Skeleton v0.3`，继续用宏观压力场景和全局视图检查一级骨架稳定性，不进入局部专题细节。

### Skeleton v0.3 第一轮宏观压力测试

八类压力场景已经完成第一轮联合测试：

- 3 个场景由现有骨架直接闭合；
- 5 个场景要求加强现有关系；
- 没有发现新增一级面、全局流、尺度轴或横切维度；
- 十面稳定性保持。

本轮加强三项宏观关系：相关失效域不能被默认独立；来源限制、纠正义务和影响责任随对象传播；跨年知识需要绑定当时的能力代际以支持回放。

该轮压力测试结束时，`Skeleton v0.3` 尚未闭合；随后进入循环权威和单点认知复核，再建立能力演进作用全域图与一屏全景。

### Skeleton v0.3 循环权威与单点认知复核

本轮识别 8 类危险循环和 10 类单点认知，确认多个 Agent、模型、来源、区域或审核者不自动构成独立判断。

宏观断环依靠：权威来源可追溯、挑战路径独立、分歧可持久、现实锚点独立、确定性边界位于 Agent 之外，以及按风险购买认知独立性。低风险任务保持单路径与 Tool 校验，高风险任务才引入不共享失败根的反证、独立审核和必要人类裁定。

本轮没有新增一级面、全局流或横切维度，十面稳定性保持。下一步建立能力演进作用全域图。

### Skeleton v0.3 能力演进作用全域

本轮把演进对象整理为体验、产品、认识研判、领域、治理组织、运行、知识数据、平台横切、承载架构九类，并建立 R1 局部替换至 R5 架构骨架五级变更半径。

能力演进面拥有观察、缺口、候选、实验、评测、影响分析和采用建议；对象所有面保留领域验收，治理与有权人类保留高影响采用，平台控制负责发布期望状态，运行面负责实际生效，数据底座保存证据和历史。

本轮确认全域覆盖不等于全域所有权；自主程度也不等于变更半径。没有新增或拆分一级面的必要，十面稳定性保持。`Skeleton v0.3` 只剩一屏全景汇总与一级稳定性复核。

### Skeleton v0.3 闭合与一级稳定性复核

一屏全景图已经完成，保留外部主权、皇帝入口、五域十面、三省六部映射、情报主干、运行与横切坐标、生存负空间、基础设施和全域演进九类最小阅读锚点。

一级复核确认 v0.2 与 v0.3 连续两轮未新增、删除或重划十面；v0.3 七道完整性门在宏观/骨架级通过，第三轮宏观骨架正式闭合。

v1.0 八项完成门槛预检查均已有证据，但本轮不直接晋级。下一步单独执行 `Skeleton v1.0` 正式就绪评审，裁定允许带入基线的保留项、基线冻结方式和后续专题入口。

### v1.0 评审前骨架重新整理

在不移动或删除既有文件的前提下，当前骨架重新组织为九层稳定阅读树：

```text
定位与前提
→ 外部上下文与主权
→ 一级逻辑职责
→ 组织治理映射
→ 情报语义与对象
→ 全局运行与协作
→ 架构坐标与横切治理
→ 生存、负空间与信任边界
→ 全域能力演进
→ 骨架验证与版本闭合
```

本轮只整理信息架构，不改变十面、七流、四轴、七维或任何权威决定。根入口、当前架构入口和文字图集改为分层导航，已有编号与链接保持稳定。
