# v0001 开放问题

状态：Draft

## Q-0001：三省是否必须始终由 Agent 实现

三省代表三种权力，但权力主体不必等于每个任务都调用大模型。需要确定：

- 中书省是否可以对模板化任务跳过 Agent；
- 尚书省 Agent 与 Workflow Engine 如何分权；
- 门下省能否对低风险结果只执行确定性验证；
- 什么风险等级强制进入三省 Agent。

## Q-0002：尚书省、钦天监与 AgentOS Scheduler 如何分工

当前三者都涉及“调度”：

- 尚书省负责业务级动态编排；
- 钦天监负责定时监测、异常发现和触发；
- AgentOS Scheduler 负责运行时排队、租约、重试和资源调度。

需要建立统一任务模型，防止三套调度状态互相覆盖。

## Q-0003：门下省、刑部、大理寺与都察院如何分工

四者均涉及审核或裁定，候选区分是：

- 门下省：对任务计划和最终结论行使独立审核权；
- 刑部：提供法规、合规和风险领域能力；
- 大理寺：处理事实主张之间的冲突；
- 都察院：持续审计系统行为和质量。

需要用同一争议事实场景验证是否仍有职责重叠。

## Q-0004：户部与枢密院如何处理成本治理

候选区分是：

- 户部负责计量、预算、成本预测和资源建议；
- 枢密院负责不可绕过的调用策略和上限强制执行；
- 皇帝或仙人负责超预算授权；
- 尚书省负责在已批准预算内选择执行和降级路径。

需要明确谁能冻结任务、谁能申请增拨、谁能批准增拨。

## Q-0005：吏部人物情报与 Agent 任免是否属于同一边界

吏部同时可能承担：

- 对天下人物、机构和任职关系的情报业务；
- 对朝廷内部 Agent Registry、能力和任免的治理职责。

需要判断这是一个双重职责官署，还是应拆成业务吏部与平台级 Agent Registry。

## Q-0006：皇帝和翰林院谁拥有最终表达权

候选区分是：

- 翰林院负责报告结构、模板、引用和渠道适配；
- 皇帝负责结合当前仙人的目标进行最终解释和对话；
- 门下省负责确保表达没有改变已审核结论。

需要设计防止润色阶段改变事实语义的机制。

## Q-0007：“核心常驻 Agent”应如何正式命名

模型进程不应持续运行。候选术语包括：

- 稳定注册 Agent；
- 核心逻辑 Agent；
- 常设 Agent 身份；
- 按需实例化的常设官职。

需要在术语表中选择不会误导运行模型的正式名称。

## Q-0008：部级 Agent 是否应默认参与每次任务

候选原则是优先使用数据库、Tool、规则和专用模型，只有遇到歧义、冲突和跨域综合时才升级到部级 Agent。

需要定义：

- 升级条件；
- 风险阈值；
- 预算阈值；
- Tool 结果是否足以直接进入门下审核；
- 部级 Agent 被跳过时由谁形成部门奏报。

## Q-0009：天机阁应被定义为超级 Agent 还是 Agent 化系统

产品叙事可以把天机阁描述为一个超大型 Agent，但技术架构显示它包含独立的数据、运行、权限、治理和多租户系统。

需要决定正式术语是否采用：

- Agentic Intelligence System；
- Agent 驱动的情报平台；
- 企业级智能情报操作系统；
- 逻辑超级 Agent。

## Q-0010：数据分配是否构成独立领域

当前“数据分配”至少包括：

- 领域路由；
- 存储路由；
- 权限域分配；
- 租户和用户产品分发。

需要判断它们共享一个统一分配模型，还是分别属于工作流、数据架构、IAM 和产品订阅系统。

## Q-0011：怎样证明 Token 优化没有损害功能

需要定义可比较的基准：

- 任务验收条件；
- 证据覆盖率；
- 事实准确率；
- 风险漏检率；
- 调查完整度；
- 延迟和成本；
- Agent 跳过后的升级恢复率。

## Q-0012：租户可以定制哪些 Agent 跳过与升级策略

租户可以拥有不同预算和风险偏好，但不能关闭平台强制的安全和合规控制。需要区分：

- 平台强制策略；
- 租户管理员策略；
- 用户任务偏好；
- 不可覆盖的审核闸门。

## Q-0013：公共事实验证成本如何在租户之间分摊

公开资料和公共事实可以共享一次处理，但不同租户可能提出不同证据深度和时效要求。需要设计：

- 首次验证成本；
- 增量验证成本；
- 公共底座维护成本；
- 私有增强成本；
- 热点公共实体的公平调度。

## Q-0014：宏观树的稳定边界是什么

树形骨架需要长期稳定，但横切关注点和领域边界可能不断变化。需要确定：

- 哪些节点属于架构宪法；
- 哪些节点属于可替换视图；
- 什么变化需要新迭代；
- 什么变化只需要补充节点内容。
