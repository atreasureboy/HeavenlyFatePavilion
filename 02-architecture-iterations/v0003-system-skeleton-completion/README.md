## 一、迭代目标

在不推翻 Skeleton v1.0 外层十面基线的前提下，从 G0 外层定位骨架继续展开 G1 一级面内部系统骨架、G2 关键机制骨架和 G3 全局连接闭合。

本轮遵循用户确认的阶段定义：

> 天机阁仍处于整体架构骨架完善阶段；外层骨架完成只是里程碑，不是整个骨架阶段出口。

## 二、工作原则

```text
先横向补齐同一分辨率
→ 再纵向进入下一层
→ 每轮重新检查跨面连接
→ 暂不进入字段、算法、选型和部署
```

Windows、三省六部和其他成熟体系用于扫描缺失结构，不直接决定正式实现。
