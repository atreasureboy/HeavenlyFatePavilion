# 架构迭代

状态：Reference

这里保存天机阁每一轮架构演进的历史：

```text
输入的新需求或新思路
→ 当前架构冲突分析
→ 候选方案
→ 场景推演
→ 质量属性与风险评估
→ 架构决定
→ 更新当前架构
```

任何会改变系统边界、权力关系、核心领域语义、数据所有权、安全模型或运行模型的变化，都应建立一轮正式迭代。
