# TXT-0016：空间、时间与规模坐标图

状态：Accepted

## 一、这张图回答什么

回答天机阁从一次查询扩展到跨租户、跨区域、跨年和超大规模运行时，整体骨架如何变化，以及哪些语义始终不变。

图中：

- 方框表示逻辑作用域或结构；
- 横轴表示可以独立变化的尺度；
- `×` 表示正交组合，不表示调用；
- `──▶` 表示尺度扩大；
- 本图有意省略部署节点、容量数字、协议和算法。

权威正文：[空间、时间与规模骨架](../spatiotemporal-and-scale-skeleton.md)。

## 三、空间关系不是一棵树

```text
                         [共享平台与公共基线]
                             /          \
                            /            \
                    [租户朝廷 A]        [租户朝廷 B]
                       │                    │
                  [用户 / Mission]     [用户 / Mission]
                       \                    /
                        \── [受控联合空间] ─/

辖域覆盖层：    [区域甲] [区域乙] [跨区域规则] [外部联邦边界]
                   ×       ×          ×              ×
作用域结构：    平台、租户、联合空间、用户与任务均可能跨越或受其限制
```

租户层级表达所有权与隔离；辖域覆盖表达法律、来源、处理、交付和行动边界。二者不能合并为单一父子树。

## 四、扩展时发生什么

```text
空间扩大
→ 隔离 + 有限联合 + 辖域覆盖 + 联邦边界

时间拉长
→ 持久目标 + 历史版本 + 更正血缘 + 跨代连续性

规模增大
→ 可分解 + 可分治 + 可限流 + 可降级 + 可汇聚 + 故障隔离

模型变强
→ Agent / Tool 边界移动，执行角色可以合并
→ 主权、制衡、证据、语义分层、审计与可停止性不随之消失
```

## 五、不可变化的中心

```text
拓扑可以变化
角色数量可以变化
模型能力可以变化
运行跨度可以变化

但：

Authority ≠ Intelligence
Fact ≠ Inference
Decision ≠ Execution
Public ≠ Unrestricted
Federation ≠ Merger
Local Conclusion ≠ Global Conclusion
Agent Context ≠ Durable Knowledge
```

## 六、有意省略

- 物理区域、集群、节点与网络；
- 分片、复制、共识和一致性模型；
- 容量、延迟、可用性和恢复指标；
- 热点调度、背压与资源算法；
- 联邦和联合空间的详细协议；
- 具体法规与数据驻留规则。
