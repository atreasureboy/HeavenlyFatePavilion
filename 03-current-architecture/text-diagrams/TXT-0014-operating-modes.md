# TXT-0014：天机阁全局运行形态与转换图

状态：Accepted

## 这张图回答什么

天机阁除了即时对话之外还以哪些形态运行；长期使命、一次执行和临时 Agent 如何分离；各种形态如何转换。

## 一、统一运行层级

```text
┌──────────────────────────────────────────────────────────────┐
│ Mandate / Authority                                         │
│ 人类决定 · 长期授权 · Court Policy · 平台职责 · 外部制度   │
└──────────────────────────────┬───────────────────────────────┘
                               │ why allowed
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ Mission / Incident / Evolution Goal                          │
│ 长期目标 · 验收 · 责任 · 终止条件                           │
└──────────────────────────────┬───────────────────────────────┘
                               │ one attempt
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ Run                                                          │
│ 时间 · 版本 · 预算 · 上下文 · 执行图                         │
└──────────────────────────────┬───────────────────────────────┘
                               │ instantiate
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ Task / Agent Instance / Worker / Tool Invocation             │
│ 临时执行主体，可暂停、替换、回收                             │
└──────────────────────────────┬───────────────────────────────┘
                               │ produce
                               ▼
┌──────────────────────────────────────────────────────────────┐
│ Product / Alert / Knowledge State / Version / External Effect│
└──────────────────────────────┬───────────────────────────────┘
                               │ feedback / world change
                               └───────────────▶ 新 Run 或 Mission 变更
```

## 二、十种运行形态

```text
人类同步触发
├── M1 即时交互与快速查询
└── M2 复杂调查与案件

时间与世界变化触发
├── M3 持续监测与守望
├── M4 事件驱动响应
├── M5 周期批处理、回填与重建
└── M7 主动情报与订阅交付

多主体触发
└── M6 多人、多 Agent 与跨租户协作

系统自身状态触发
├── M8 能力观察、实验与演进
└── M10 事故、降级与灾难恢复

有权决定触发
└── M9 受控外部行动与补偿
```

## 三、形态转换

```text
[M1 快速查询] ──复杂度/风险上升──▶ [M2 复杂调查]
                                            │
                                            ├──需要会盟──▶ [M6 协作]
                                            └──获行动授权▶ [M9 外部行动]

[M3 持续监测] ──发现 Change/Risk──▶ [M4 事件响应]
                                            │
                                            ├──影响扩大──▶ [M2 复杂调查]
                                            └──需通知────▶ [M7 主动交付]

[任意生产形态] ──需要重算/修复────▶ [M5 批处理回填]
[任意运行形态] ──发现能力缺口────▶ [M8 能力演进]
[任意运行形态] ──重大事故────────▶ [M10 灾难恢复]
[M10 灾难恢复] ──纠正派生影响────▶ [M5 回填] + [M7 更正交付]
```

## 四、Trigger 与授权

```text
Human / Time / World Event / Internal State /
Policy / Evolution / Emergency Trigger
                     │
                     ▼
              [候选工作信号]
                     │
           检查 Mandate / Policy
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
      创建/继续 Run          抑制/合并/拒绝
```

```text
Trigger ≠ Mission
Mission ≠ Run
Run ≠ Agent
Recommendation ≠ Command
Command Success ≠ Real-world Effect
```

## 五、时间尺度

```text
毫秒 ─────────────────────────────────────────────── 年
 │       │             │              │              │
强制点  查询/告警     调查/审核      案件/批处理     监测/演进
隔离    快速降级      产品/补证      灰度/恢复       架构迭代
```

不同时间尺度共享同一作用域、授权、证据、预算和审计语义。

## 六、与十面的关系

```text
运行形态
   │ 决定参与强度，不改变一级归属
   ▼
人机交互 · 情报产品 · 数据认知 · 情报研判 · 智能治理
领域能力 · 智能执行与运行 · 数据底座 · 平台控制 · 能力演进
```

没有任何运行形态拥有“绕过十面契约”的后台特权。

## 七、箭头语义与刻意省略

- `▶` 表示运行形态或生命周期转换；
- `+` 表示一个恢复结果触发多个后续形态；
- 本图不规定同步/异步、队列、工作流引擎和服务数量；
- 不规定 RTO/RPO、批量大小和模型选择；
- M9 保留外部行动的骨架位置，不表示默认启用。
