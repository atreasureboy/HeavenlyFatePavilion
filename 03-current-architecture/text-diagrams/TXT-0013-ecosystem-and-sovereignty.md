# TXT-0013：天机阁主体生态与主权边界图

状态：Accepted

## 这张图回答什么

天机阁周围有哪些主体；谁治理、授权、供应、审核、消费、行动、纠正或对抗；皇帝和内部 Agent 的权力从哪里来、在哪里终止。

## 二、内部与外部主体分层

```text
外部原生权威
├── 人类目标与责任
├── 法律、监管与权利制度
├── 数据、内容和来源权利
├── 外部系统业务状态
└── 供应商内部服务状态
              │ 授权 / 约束 / 契约
              ▼
平台与租户期望状态
├── 平台宪制与准入政策
├── Tenant / Court Profile
├── 身份、预算与数据范围
└── Mission 决定
              │ 派生、限域、限时、可撤销
              ▼
天机阁内部智能主体
├── 皇帝
├── 三省
├── 六部与官署 Agent
├── Runtime / Worker / Tool
└── 确定性策略与强制点
```

内部主体没有“自生权力”。

## 三、分域主权

```text
┌────────────────┬──────────────────────────┬──────────────────────┐
│ 主权域         │ 原生权威                 │ 天机阁不能冒充       │
├────────────────┼──────────────────────────┼──────────────────────┤
│ 人类目标与责任 │ 有权仙人/责任人          │ 最终业务责任人       │
│ 平台运行       │ 平台治理与运营者         │ 外部法律制定者       │
│ 租户资源       │ Tenant Owner/Admin       │ 其他租户             │
│ 数据使用       │ 权利人+许可+适用制度      │ 无条件数据所有者     │
│ 事实接受       │ 可审计验证制度           │ 现实真相垄断者       │
│ 情报产品       │ 发布决定者+产品所有者     │ 无权受众的授权者     │
│ 外部行动       │ 外部系统+行动责任主体     │ 外部业务状态所有者   │
│ 法律公共约束   │ 适用制度与权威机构        │ 规则的任意改写者     │
│ 能力版本       │ 平台发布治理             │ 供应商输出的盲信者   │
└────────────────┴──────────────────────────┴──────────────────────┘
```

## 四、皇帝权力的交集

```text
平台允许能力
        ∩
Court Profile
        ∩
当前仙人权限
        ∩
Mission 委托
        ∩
数据与来源许可
        ∩
风险 / 预算 / 时间条件
        =
皇帝本次有效权力
```

模型更聪明、皇帝知道更多、Tool 技术上可调用，都不会扩大这个交集。

## 五、九种生态关系

```text
Govern    制定适用制度
Authorize 授予有限能力
Request   提出目标或服务请求
Supply    供应数据、能力或知识
Observe   成为合法研究或监测对象
Review    审核事实、研判或系统行为
Consume   消费产品、告警或 API
Act       改变外部业务状态
Challenge 纠正、申诉、撤回、审计或对抗
```

```text
Supply ≠ Authorize
Consume ≠ Read All Evidence
Operate Platform ≠ Use Tenant Data
Call External System ≠ Own External Result
Organizational Power ≠ Fact Truth
```

## 六、权威冲突路由

```text
[Authority Conflict]
          │ 标记主体 / 主权域 / 作用域 / 时间
          ▼
停止不可逆或高影响路径
          │
          ├── 权限/政策 ─▶ 平台控制 + 枢密院
          ├── 法规合规 ─▶ 刑部 + 外部权威
          ├── 事实主张 ─▶ 数据认知 + 大理寺
          ├── 程序审计 ─▶ 都察院
          └── 最终责任 ─▶ 有权人类
```

## 七、箭头语义与刻意省略

- `◀─▶` 表示存在受控交换，不表示相互信任；
- `▶` 表示约束、授权、供应或影响；
- 图中“主权”表示特定域内的最终权威，不表示国家政治主权；
- 暂不展开具体法律优先级、RBAC/ABAC、审批链和外部行动协议；
- 对抗主体的攻击路径留给后续生存性骨架扫描。
