# TXT-0007：天机阁十面输入输出契约图

状态：Accepted

## 这张图回答什么

十个一级面分别接收什么、输出什么、保存什么，以及请求失败后退回哪里。

箭头上的文字是主要契约，不代表底层传输协议。

## 二、每面六项摘要

```text
人机交互面
输入：消息、产品、决定请求
输出：Intent、Feedback、交付
状态：会话、投影、回执
退回：主体不明、意图不清

情报产品面
输入：已审核事实与研判
输出：Product、Alert
状态：产品版本、发布、分发
退回：证据不足、类型混写

数据认知面
输入：资料、任务、领域规则
输出：Evidence、Claim、Fact候选、世界状态
状态：认知形成语义
退回：来源不明、无法消歧、缺少证据

情报研判面
输入：事实、变化、领域知识
输出：Assessment、Forecast、Risk
状态：假设、研判与校准
退回：事实不足、时间不明、不确定性不可控

智能治理面
输入：Intent、状态、证据、研判、候选
输出：Mission、Plan、Decision
状态：治理议程、审议、责任链
退回：目标、证据、预算、授权或验收不足

领域能力面
输入：领域问题和共享对象
输出：本体、规则、领域判断、能力缺口
状态：领域能力逻辑版本
退回：领域错配、专业边界不足

智能执行与运行面
输入：批准 Plan、Task、期望状态
输出：Run、Event、Result、Failure
状态：即时执行状态
退回：版本、上下文、能力或预算不满足

数据底座面
输入：有类型对象、版本、血缘
输出：权威读取、历史、索引、变更事件
状态：持久对象与双时态
退回：Schema、作用域、血缘或所有权不合法

平台控制面
输入：配置决定、实际状态、演进候选
输出：Court Profile、Policy、Template、Version
状态：长期期望状态
退回：冲突、依赖不兼容、无法回滚

能力演进面
输入：质量、成本、失败、反馈、时代变化
输出：Gap、Candidate、Experiment、Evaluation
状态：演进证据与候选
退回：不可复现、无评测、不可回滚
```

## 三、统一退回路径

```text
目标不清 ─────────────▶ 人机交互面
计划、审核或裁定问题 ─▶ 智能治理面
领域错配 ─────────────▶ 领域能力面 / 尚书省重新分部
证据、消歧、变化问题 ─▶ 数据认知面
研判与不确定性问题 ──▶ 情报研判面
执行、资源、故障问题 ─▶ 智能执行与运行面
数据版本与血缘问题 ──▶ 数据底座面
配置、策略、目录问题 ─▶ 平台控制面
能力退化与改进问题 ──▶ 能力演进面
产品内容或分发问题 ──▶ 情报产品面 / 人机交互面
```

## 四、契约信封

```text
Plane Contract Envelope
├── 谁发给谁
├── 做什么类型的交互
├── 哪个租户、主体、Mission、Run、Task
├── 使用哪个 Court Profile 和契约版本
├── 输入对象引用与前置条件
├── 期望结果与证据要求
├── 权限、预算、风险和时限
├── 幂等、追踪与因果标识
└── 失败应该退到哪里
```

## 五、有意省略

- 具体 API 和消息协议；
- Schema 字段类型；
- 授权矩阵；
- 超时、重试和补偿数值；
- 服务级目标；
- 奏折等官制叙事协议名称。
