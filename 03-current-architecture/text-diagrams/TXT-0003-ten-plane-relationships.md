# TXT-0003：十面关系与依赖图

状态：Accepted

## 这张图回答什么

十个一级面不是简单上下层关系，它们之间分别交换什么，以及哪些面拥有状态、处理语义、治理权或交付责任。

## 二、状态与责任归属

```text
人机关系与会话投影          → 人机交互面
情报交付物与产品版本        → 情报产品面
认知处理语义                → 数据认知面
研判处理语义                → 情报研判面
任务治理决定                → 智能治理面
领域本体、规则与专业能力    → 领域能力面
Run / Task / 实例状态       → 智能执行与运行面
事实、证据、关系与历史状态  → 数据底座面
模板、策略与期望状态        → 平台控制面
演进候选、实验与评测状态    → 能力演进面
```

## 三、最容易混淆的边界

```text
皇帝交互投影 ≠ 皇帝治理本体
情报产品组织 ≠ 情报研判
数据认知处理 ≠ 数据持久化
三省治理权   ≠ 六部专业能力
尚书省编排   ≠ 运行时调度器
Agent Template ≠ Agent Instance
Agent Memory ≠ 情报数据库
能力演进     ≠ 普通运行维护
基础设施承载 ≠ 一级逻辑职责
视觉分组“域” ≠ 新的所有权层
```
