## 二、Agent 与 Tool 分界

```text
需要规划、跨域判断、多步决策、反证审核、综合解释
                               │
                               ▼
                         使用高级 Agent
        皇帝 / 三省 / 部级主官 / 复杂裁定与调查角色

确定性强、重复频率高、高吞吐、结构化、可由规则稳定执行
                               │
                               ▼
                    使用 Tool / Script / Service
        采集 / 清洗 / Diff / 索引 / 检索 / 规则 / 存储 / 监控
```

## 三、皇帝不直接拥有全部能力

```text
皇帝拥有：
统一关系、全局协调、任务发起、治理视图、主动汇报和最终解释

皇帝不拥有：
全部原始数据副本、所有工具权限、无限预算、免审核权、
每个领域的全部知识、绕过运行系统直接执行一切的能力
```
