## 一、这张图回答什么

图中：

- `──▶` 表示正向作用；
- `◀──` 表示反馈；

- `║` 表示必须存在的可区分边界；

## 二、受治理闭环与自证回路

```text
受治理闭环：

[产生候选] ──▶ [证据 / 结果] ──▶ [独立接受边界]
     ▲                                 │
     │                                 ▼
     └──── [有来源的反馈] ◀──── [发布 / 执行]

特点：
权威来源可追溯 / 可拒绝 / 可保留分歧 / 可停止 / 历史不覆盖


自证回路：

[产生结论] ──▶ [选择支持证据] ──▶ [审核自己]
     ▲                                   │
     └──────── [删除失败记录] ◀── [批准自己]

                         × 禁止
```

## 四、单点认知不是单点服务

```text
                     [共同认知根]
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   [中书 Agent]       [尚书 Agent]       [门下 Agent]
        │                  │                  │
        └──────────────────┼──────────────────┘
                           ▼
                    [看似三方一致]

共同认知根可能是：
同一模型族 / 同一检索索引 / 同一来源家族 / 同一本体
同一实体解析 / 同一事实视图 / 同一评测标准 / 同一摘要

多个实例 ≠ 多个独立判断
```

## 五、断环结构

```text
人类、平台、租户、Mission
──────────── 权力来源 ────────────▶ [授权与决定]
                                       ║
[候选 / 假设] ──▶ [证据与血缘] ──▶ [事实接受]
       │                               ║
       └──▶ [反证 / 替代解释] ───────▶ [独立审核]
                                       ║
[外部动作] ──▶ [回执] ──▶ [现实独立观察 / Effect]
                                       ║
[生产结果] ──▶ [多源评测] ──▶ [演进批准 / 发布]

全部路径：
可审计 + 可拒绝 + 可停止 + 可纠正 + 失败根可追溯
```

## 六、按风险购买认知独立性

```text
低风险 / 可逆 / 确定性强
→ 单路径 + Tool 校验 + 可追溯

中风险 / 开放式判断
→ 反证 + 来源差异 + 不确定性

高风险 / 不可逆 / 跨主权
→ 不共享失败根的验证 + 独立审核 + 必要人类裁定
```

多 Agent 不是默认仪式。认知独立性应按风险启用，既防止自证，也控制 Token 消耗。

## 七、四项骨架加强

```text
受治理闭环 ≠ 自证回路
系统干预现实 ──必须进入──▶ 因果与审计血缘
认知独立性 ──必须检查──▶ 共同失败根
反证强度 ──随风险增加──▶ 不随 Agent 数量表演
```
