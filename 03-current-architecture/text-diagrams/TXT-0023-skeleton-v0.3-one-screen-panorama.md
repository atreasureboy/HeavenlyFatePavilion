# TXT-0023：Skeleton v0.3 一屏全景图

状态：Accepted

## 一、这张图回答什么

用一个压缩视图回答：天机阁由谁授权、如何治理、如何生产情报、由什么持久承载、怎样跨租户和时空运行、如何生存与演进。

图中：

- `──▶` 表示主要业务或知识方向；
- `══▶` 表示目标、授权、治理或发布；
- `◀──` 表示反馈、纠正或实际状态；
- `×` 表示横切坐标与约束；
- 方框表示逻辑职责或外部主体，不表示部署节点；
- 该图只用于建立完整心智模型，精确语义由专题图和正文定义。

权威基线：[总体一级逻辑骨架](../overall-logical-skeleton.md)。

## 三、读图顺序

```text
1. 外部主体提供目标、权力、资料、制度与现实反馈
2. 皇帝提供统一交互和全局协调，但不拥有无限权力
3. 十面分别拥有体验、产品、认知、研判、治理、领域、运行、知识、
   控制和演进职责
4. 三省六部是组织映射，不是第二套技术架构
5. 情报主干把原始资料转化为事实、变化、趋势、风险和产品
6. 四轴、七维、七流、生存边界与负空间共同限制所有任务
7. 基础设施共同承载，但不取得业务、事实或治理权
8. 运行结果回到演进体系；演进覆盖全域，但不拥有全域采用权
```

## 四、有意省略：这张图刻意不画什么

- 二级能力树和官署内部结构；
- 对象字段、状态转移和契约消息；
- 逐场景调用顺序；
- Agent 实例数量和模型选择；
- 数据库、队列、网络、区域和部署拓扑；
- 安全、容量、成本和恢复参数。

省略这些内容是为了保持一屏心智模型，不表示它们不属于完整架构卷宗。

## 六、稳定中心

```text
Human Authority ≠ Agent Intelligence
Plan ≠ Execution ≠ Review
Document ≠ Snapshot ≠ Evidence ≠ Claim ≠ Proposition
Fact Aggregate ≠ Assessment ≠ Forecast ≠ Recommendation
Recommendation ≠ Decision ≠ Command ≠ Effect
Agent Context ≠ Durable Knowledge

```
