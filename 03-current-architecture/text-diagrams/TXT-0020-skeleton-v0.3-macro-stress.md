# TXT-0020：Skeleton v0.3 宏观压力测试图

状态：Accepted

## 一、这张图回答什么

回答八个极端场景如何攻击天机阁整体骨架、现有结构是否被击穿，以及压力测试产生了哪些跨场景加强项。

图中：

- `──▶` 表示压力作用或处理方向；
- `×` 表示同时攻击多个结构；
- `[C]` 表示现有骨架闭合；
- `[R]` 表示无需新一级结构但需要加强；
- 本图省略协议、时序、算法和部署。

权威分析：[Skeleton v0.3 第一轮宏观压力测试](../../07-analysis-and-validation/skeleton-v0.3-macro-stress-test.md)。

## 三、场景与骨架响应

```text
[P1 多辖域冲突]
──▶ 辖域覆盖 + 政策强制 + 分域裁定 + 外部权威

[P2 联邦污染]
──▶ 外部 Fact 降格为 Claim/Evidence + 本地验证 + 纠正血缘

[P3 热点拥塞]
──▶ 公平与优先级 + Tool 筛选 + 显式降级 + 认知拥塞控制

[P4 区域中断]
──▶ 人类控制 + 权力根 + 隔离 + 权威记录 + 真实态势 + 恢复纠正

[P5 联合污染]
──▶ 供应链血缘 + 相关失效域 + 非共同失效候选 + 派生纠正

[P6 超级模型]
──▶ 实例可合并 + 权力可区分 + 外部强制 + 人类接管

[P7 效果失败]
──▶ Decision ≠ Command ≠ Acknowledgement ≠ Observed Effect

[P8 历史重释]
──▶ 旧能力 / 旧知识保留 + 当前重释 + 产品纠正 + 历史不改写
```

## 四、三项跨场景加强

```text
1. 相关失效关系

多来源 ≠ 独立证据
多模型 ≠ 独立判断
多区域 ≠ 独立控制根
多副本 ≠ 独立副本

2. 派生义务与影响传播

对象跨域传播
──必须携带──▶ 来源限制 / 授权义务 / 纠正义务 / 影响责任

3. 跨能力代际可回放

历史结论
──必须绑定──▶ 当时数据 + 当时规则 + 当时模型 / Tool + 当时授权
```

三项加强分别落入现有证据血缘、风险质量、生命周期、审计和能力演进连接，不形成新的面、流、轴或横切维度。
