# TXT-0002：三条核心闭环图

状态：Accepted

## 这张图回答什么

天机阁如何从用户目标产生情报，如何持续监测世界，以及如何根据运行效果演进自身。

箭头表示逻辑顺序和反馈，不表示所有步骤都必须串行执行。

## 一、需求与治理闭环

```text
                       ┌───────────────────┐
                       │       仙人        │
                       │ 目标 / 决定 / 反馈 │
                       └─────────┬─────────┘
                                 │
                                 ▼
                       ┌───────────────────┐
                       │   皇帝交互投影     │
                       └─────────┬─────────┘
                                 │ 意图与上下文
                                 ▼
                       ┌───────────────────┐
                       │   皇帝治理本体     │
                       │ 全局统筹与关系维持 │
                       └─────────┬─────────┘
                                 │
              ┌──────────────────┴──────────────────┐
              ▼                                     │
     ┌─────────────────┐                            │
     │ 中书省：规划起草 │                            │
     └────────┬────────┘                            │
              │ 任务契约                            │
              ▼                                     │
     ┌─────────────────┐  封驳 / 补证 / 降级        │
     │ 门下省：审议审核 │──────────────────────┐     │
     └────────┬────────┘                      │     │
              │ 通过                          │     │
              ▼                               │     │
     ┌─────────────────┐                      │     │
     │ 尚书省：执行统筹 │◀─────────────────────┘     │
     └────────┬────────┘                            │
              │ 执行图                               │
              ▼                                     │
     ┌─────────────────┐                            │
     │ 运行面 + 六部    │                            │
     │ Agent / Tool     │                            │
     └────────┬────────┘                            │
              │ 结果、证据、执行记录                 │
              ▼                                     │
     ┌─────────────────┐                            │
     │ 门下复核 / 裁定  │────────退回────────────────┘
     └────────┬────────┘
              │ 已审核结果
              ▼
     ┌─────────────────┐
     │   情报产品面     │
     └────────┬────────┘
              │
              ▼
     ┌─────────────────┐
     │ 皇帝解释与汇报   │
     └────────┬────────┘
              │
              └──────────────────────────────▶ 仙人
```

低风险、可复用、已有权威事实的任务允许走缩短路径；缩短路径必须由治理策略定义，而不是某个 Agent 自行绕过。

## 二、持续情报生产闭环

```text
  ┌───────────────────────────────────────────────────────────────────────┐
  │                          监测目标 / 用户问题                          │
  └────────────────────────────────┬──────────────────────────────────────┘
                                   ▼
       ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
       │  掌数  │──▶│  联结  │──▶│  察变  │──▶│  推势  │──▶│  卜算  │──▶│  警险  │
       └───┬────┘   └───┬────┘   └───┬────┘   └───┬────┘   └───┬────┘   └───┬────┘
           │            │            │            │            │            │
           └────────────┴────────────┴──────┬─────┴────────────┴────────────┘
                                            ▼
                                  ┌───────────────────┐
                                  │    情报产品面      │
                                  └─────────┬─────────┘
                                            │
                                            ▼
                               (反馈 / 新证据 / 新目标 / 结果验证)
                                            │
                ┌───────────────────────────┴───────────────────────────┐
                │                                                       │
                └──────────────▶ 掌数 / 联结 / 察变 / 推势 ◀───────────┘

  六部领域能力覆盖整条主干：
  [吏部] × [户部] × [礼部] × [兵部] × [刑部] × [工部]
```

这条主干不是 ETL 管道。它允许从任何研判阶段反向要求补充资料、重新消歧、寻找反证或修正监测目标。

## 三、控制、运行与能力演进闭环

```text
┌─────────────────────────────────────┐
│            平台控制面               │
│ Template / Policy / Budget / Version│
│            长期期望状态             │
└──────────────────┬──────────────────┘
                   │ 版本化下发
                   ▼
┌─────────────────────────────────────┐
│        智能执行与运行面             │
│ Run / Task / Instance / Tool Call   │
│            即时执行状态             │
└──────────────────┬──────────────────┘
                   │ 实际状态、质量、成本、失败
                   ▼
┌─────────────────────────────────────┐
│             能力演进面              │
│ 观察 → 缺口 → 候选 → 实验 → 评测   │
└──────────────────┬──────────────────┘
                   │ 经过验证的变更候选
                   ▼
┌─────────────────────────────────────┐
│             智能治理面              │
│ 审议 / 反证 / 风险判断 / 人类决定   │
└──────────────────┬──────────────────┘
                   │ 批准、拒绝或修改
                   ▼
┌─────────────────────────────────────┐
│            平台控制面               │
│ 发布新期望状态 / 灰度 / 回滚        │
└──────────────────┬──────────────────┘
                   │
                   └───────────────────────────────▶ 下一轮运行
```
