# 体验与交付域能力树

状态：Accepted

## 一、人机交互面

核心问题：仙人如何通过皇帝与整座天机阁建立持续关系。

```text
人机交互面
├── 1. 皇帝关系与人格投影能力                  [A]
├── 2. 对话与会话连续性能力                    [M]
├── 3. 多模态理解与表达能力                    [M]
├── 4. 意图启发、澄清与确认能力                [A]
├── 5. 用户偏好与交互适配能力                  [M]
├── 6. 主动通知、注意力与打断管理能力          [M]
├── 7. 反馈、纠正与追问管理能力                [M]
├── 8. 人类决定、审批与接管交互能力            [M]
├── 9. 渠道接入与消息适配能力                  [T]
└── 10. 可访问性、语言与呈现适配能力           [T]
```

### 二级能力说明

| 能力 | 主要内容 | 明确不包含 |
|---|---|---|
| 皇帝关系与人格投影 | 统一人格、关系连续性、全局态势的交互投影 | 皇帝治理决定本身 |
| 对话与会话连续性 | 会话、上下文切换、引用、恢复和多轮一致性 | 权威事实存储 |
| 多模态理解与表达 | 文本、语音、图像、文件和可视化交互 | 底层 OCR 或模型运行 |
| 意图启发与澄清 | 从模糊表达形成可提交 Intent | Mission 规划 |
| 用户偏好适配 | 语言、粒度、节奏、关注和交付偏好 | 篡改公共事实 |
| 主动通知管理 | 提醒、告警、打断、摘要和注意力优先级 | 风险判定 |
| 反馈纠正管理 | 将反馈绑定到目标对象并确认影响 | 直接修改 Fact |
| 人类决定与接管 | 审批、否决、选择、暂停和接管入口 | 判断谁拥有决定权的策略 |
| 渠道接入 | Web、API、IM、邮件、移动和终端适配 | 业务任务执行 |
| 可访问性与语言 | 本地化、无障碍和终端呈现适配 | 情报产品内容生成 |

## 二、情报产品面

核心问题：已形成的事实和研判如何成为稳定、可追溯、适合受众的交付物。

```text
情报产品面
├── 1. 即时回答与查询结果编排能力              [M]
├── 2. 人物、机构、项目与主题档案能力          [M]
├── 3. 图谱、关系与网络视图能力                [T]
├── 4. 事件、变化与时间线产品能力              [T]
├── 5. 简报、报告与调查卷宗能力                [M]
├── 6. 态势、趋势与情景产品能力                [M]
├── 7. 风险告警与持续跟踪产品能力              [M]
├── 8. 证据展开与可信解释能力                  [T]
├── 9. 订阅、分发与交付确认能力                [T]
└── 10. 产品版本、更正、撤回与归档能力         [T]
```

### 二级能力说明

| 能力 | 主要内容 | 明确不包含 |
|---|---|---|
| 即时回答编排 | 基于已授权对象形成回答和引用 | 重新判定事实 |
| 档案能力 | 聚合主体、关系、历史和研判视图 | 拥有底层唯一数据副本 |
| 图谱视图 | 关系探索、筛选、聚合和解释 | 实体消歧 |
| 时间线产品 | 事件、变化、版本和因果候选展示 | Change 形成语义 |
| 报告与卷宗 | 结构化报告、摘要、附件和审阅包 | 扩大审核结论 |
| 态势与情景产品 | 呈现 Assessment、Forecast 和情景树 | 产生预测模型 |
| 风险产品 | Alert、风险看板、升级和解除展示 | Risk 判定 |
| 证据展开 | 从产品结论追溯 Evidence 和 Snapshot | 验证 Claim |
| 订阅与分发 | 受众、渠道、频率、送达和确认 | 渠道底层实现 |
| 产品生命周期 | 草稿、审核、发布、更正、撤回、替代 | Fact 生命周期 |

## 三、边界检查

```text
交互面负责“怎样与人相处”
产品面负责“交付什么”

皇帝解释能力属于交互
报告生成与版本属于产品
态势判断属于研判
事实与证据属于数据底座和认知
```
