# 治理与执行域能力树

状态：Accepted

## 一、智能治理面

核心问题：复杂智能任务如何被理解、规划、统筹、审核、裁定和问责。

```text
智能治理面
├── 1. 皇帝全局统筹与关系治理能力              [A]
├── 2. Intent 解释与 Mission 形成能力           [A]
├── 3. 验收、证据、预算与风险条件定义能力      [A]
├── 4. Plan 设计、分解与版本化能力             [A]
├── 5. 三省审议、反证、封驳与批准能力          [A]
├── 6. 执行统筹、跨部编排与优先级治理能力      [A]
├── 7. 结果审核、质量降级与发布治理能力        [A]
├── 8. 冲突裁定、异常升级与专家复核能力        [A]
├── 9. 人类决定、接管与最终责任能力            [M]
└── 10. 治理记录、监察、问责与复盘能力         [T]
```

### 三省能力映射

```text
中书省
→ Intent 解释
→ Mission 起草
→ Plan 设计
→ 验收与证据条件提出

尚书省
→ 执行统筹
→ 六部协调
→ 优先级与资源申请
→ 结果汇集

门下省
→ 独立审议
→ 反证与封驳
→ 质量降级
→ 发布前复核
```

三省是能力和权力组合，不要求每个请求机械串行实例化三个 Agent。

### 治理边界

- 治理面决定“应该做什么以及是否接受结果”；
- 运行面决定“获批任务如何可靠执行”；
- 平台控制面保存“长期使用哪些模板和策略”；
- 人类决定能力不等于所有步骤都必须人工审批。

## 二、智能执行与运行面

核心问题：治理决定如何成为可隔离、可观测、可恢复、经济运行的实际执行。

```text
智能执行与运行面
├── 1. Run、Task 与执行图实例化能力            [T]
├── 2. Agent 实例创建与生命周期能力            [T]
├── 3. Tool、Skill、模型与外部服务调用能力     [T]
├── 4. Context 组装、裁剪与传播能力             [M]
├── 5. Memory 与 Workspace 生命周期能力         [T]
├── 6. 调度、队列、Worker 与公平执行能力        [T]
├── 7. 并发、幂等、租约、重试与补偿能力        [T]
├── 8. 超时、取消、循环与死锁控制能力           [T]
├── 9. 沙箱、隔离与能力句柄执行能力             [T]
├── 10. 故障恢复、降级与业务连续性能力          [T]
├── 11. 执行观测、成本计量与实际状态回报能力    [T]
└── 12. 人类接管、暂停与控制权回收能力          [M]
```

### 运行内核边界

```text
Agent 负责：
动态理解、选择、推理、综合和异常判断

运行内核负责：
状态机、调度、队列、重试、预算计量、隔离、超时和审计
```

不得用 Agent 模拟确定性运行内核；也不得用固定工作流冒充所有开放式智能决策。
