# v0002 情报语义基线就绪评审

状态：Accepted

评审日期：2026-07-29

## 一、结论

v0002 通过语义基线采纳门。

S1～S9 已共同形成可供后续数据、协议、运行、治理和领域专题引用的完整语义骨架；SCN-0010～SCN-0018 覆盖来源变化、权威冲突、实体误合并、变化分型、预测干预、产品纠正、迟到资料、越权转换和复合并发异常。

本轮没有改变 Skeleton v1.0 的十个一级面。它深化的是各面之间传递的对象、记录、状态、权威、时间和血缘。

## 五、矛盾审计

未发现以下结构性矛盾：

- 三省权力分离与对象 Authority Domain 相容；
- 数据底座的保管权不侵占领域语义决定权；
- 多租户覆盖不要求复制一套完整物理系统；
- Agent 与 Tool 的实现形态不改变对象的授权和血缘要求；
- 自我演进可以修改能力版本，但不能自行修改不变量或取得人类权力；
- Product Edition 的不可变性与后续 Correction / Supersession 相容；
- 双时态与 Authority Domain 认识记录可以共同重建历史。

## 六、开放问题处置

所有剩余问题被分为两类，均不阻塞基线：

1. **后续实现专题**：物理 Schema、协议字段、存储、索引、并发机制、算法、容量和成本；
2. **后续领域扩展**：Action 边界、跨租户联合调查、领域本体、证据等级和具体政策矩阵。

这些问题若在后续推演中否定本轮不变量，应通过新 ADR 重新打开基线，而不是静默修改。

## 七、采纳动作
