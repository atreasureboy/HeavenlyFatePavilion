# 循环权威与单点认知复核

状态：Accepted

复核日期：2026-07-24

所属轮次：`Skeleton v0.3`

## 一、复核目标

这轮检查两类传统组件图不容易暴露的问题：

```text
循环权威
→ 一个结果最终由自身证明、授权、评价或修正

单点认知
→ 全系统虽有多个 Agent、来源或节点，实际上共享同一判断根
```

技术高可用可以复制服务，却不能自动解决这两类问题。十个 Agent 如果共享同一模型、同一检索结果和同一评价标准，仍可能只有一个认知视角。

本轮只检查宏观权力与认识结构，不设计投票算法、模型路由、人员编制或具体审核流程。

## 二、循环是否一定错误

天机阁本来就依赖闭环：

- 研判会要求补充数据；
- 产品反馈会触发事实纠正；
- 运行证据会推动能力演进；
- 新能力又会改变后续运行。

问题不在“有回路”，而在回路是否满足：

1. 每次改变权威状态都经过有权边界；
2. 输入、决定、结果和反馈拥有不同语义；
3. 回路中存在能够拒绝、保留分歧或停止的节点；
4. 结果不能成为自己唯一的验证证据；
5. 历史版本和失败影响不能被新一轮覆盖。

满足这些条件的是受治理闭环；不满足的是自证回路。

## 三、A1：皇帝自我授权回路

### 危险回路

```text
仙人提出模糊目标
→ 皇帝解释目标
→ 皇帝把自己的解释写成授权
→ 皇帝调度执行
→ 皇帝审核结果
→ 皇帝向仙人声称任务符合原意
```

皇帝同时控制解释、授权、执行和验收，会把“统一体验”膨胀为原生主权。

### 断环位置

- 仙人、平台、租户和 Mission 委托分别提供权力来源；
- 目标解释与授权记录必须可区分；
- 三省权力可由同一模型承载，但决定类型、上下文和拒绝权分开；
- 高影响或歧义无法消除时回到有权人类；
- 皇帝不能把未获确认的扩展解释当作既有授权。

### 裁定

现有交互、治理、平台控制和人类主权边界能够断环，不新增“人类控制面”。

## 四、A2：治理—政策自授回路

### 危险回路

```text
治理 Agent 提出更宽权限
→ 能力演进把建议变成新策略
→ 平台控制发布策略
→ 新策略扩大原治理 Agent 权限
→ 治理 Agent 批准下一次扩大
```

### 断环位置

- 变更候选、评测结果、批准决定和生产发布分离；
- 受益主体不得成为唯一批准者；
- 权力根、不可扩大边界和人类保留权不由演进候选改写；
- 策略发布、运行生效和回滚保持不同状态；
- 审计保留权限变化前后的完整链条。

### 裁定

现有治理、平台控制、能力演进和审计结构能够断环。

## 五、A3：研判—采集确认偏差回路

### 危险回路

```text
初步假设
→ 只采集支持假设的来源
→ 检索和排序提高同类证据可见度
→ 研判置信度上升
→ 更强地限定后续采集
```

这会让系统“越调查越确定”，但增加的只是同源重复。

### 断环位置

- 假设、查询策略、证据和事实分层；
- 保存候选、反证、未覆盖区域和来源家族；
- 证据独立性不能按数量推断；
- 门下省拥有提出替代解释和退回补证的权力；
- 高风险任务按需引入不同来源、检索路径、模型或人类，而非永远全量多 Agent。

### 裁定

数据认知、研判、门下审核和证据血缘能够断环，但必须明确“检索结果也是有偏观察，不是世界本身”。

## 六、A4：产品—现实反馈自证回路

### 危险回路

```text
天机阁发布趋势或风险
→ 用户和外部系统据此行动
→ 行动改变现实与公开信息
→ 天机阁观察到变化
→ 把变化解释为原预测正确
```

产品可能参与制造其后来观察到的“证据”。

### 断环位置

- Recommendation、Decision、Action、Acknowledgement 与 Effect 分层；
- 产品传播和外部行动进入因果与审计记录；
- 预测校准区分自然结果与由产品介入产生的结果；
- 现实效果需要独立观察，不能由执行回执证明；
- 无法区分时标记干预污染，而不是计为成功。

### 裁定

现有产品、行动、数据认知、审计和演进结构能够断环；需要将“系统自身是世界因果参与者”保留为全局不变量。

## 七、A5：热度—资源—可见度放大回路

### 危险回路

```text
某事件初始热度更高
→ 获得更多采集、模型和人工资源
→ 产生更多资料、关系和产品
→ 在检索与告警中更可见
→ 被判定为更重要
→ 继续获得更多资源
```

结果可能是注意力垄断，而不是风险真实上升。

### 断环位置

- 热度、重要性、风险、证据量和资源投入分别表示；
- 平台控制保留公平、基础覆盖和关键任务保障；
- 户部预算建议不能成为风险裁定；
- 产品明确数据覆盖与资源倾斜；
- 能力演进评估“资源造成的可见度”而不是只学习点击和调用量。

### 裁定

预算资源流、规模轴、风险质量和平台控制能够断环，不新增资源治理面。

## 八、A6：事实—索引—重复引用回路

### 危险回路

```text
一个未经充分验证的 Claim
→ 被索引、图谱或摘要引用
→ 多个产品和网页再次引用
→ 新采集把这些派生引用视作多个来源
→ Claim 因“多源一致”升级为 Fact
```

### 断环位置

- 来源和派生血缘穿透摘要、索引、产品与联邦传播；
- 引用数量不等于独立来源数量；
- 派生产品不能反向成为原主张的独立证据；
- 事实接受检查共同根源、时间和引用关系；
- 污染发现后按反向血缘隔离并纠正。

### 裁定

证据血缘、数据底座和知识形成流能够断环。

## 九、A7：模型—评测—演进自我优化回路

### 危险回路

```text
模型生成答案
→ 同一模型生成评分标准或评判答案
→ 评测选择该模型偏好的输出
→ 演进面据此扩大模型使用范围
→ 更多生产数据继续强化同一偏好
```

### 断环位置

- 生产主体、评测设计、评价执行、批准和发布可区分；
- 评测集、现实结果、人工判断和对抗场景保留不同来源；
- 模型不能删除不利样本或批准自身上线；
- 评价标准版本化，并接受外部结果校准；
- 对高影响变更要求至少一种不共享同一失败根的验证路径。

### 裁定

能力演进、治理、平台控制与审计能够断环，但“多个模型评分”只有在失败根不同的情况下才提供真正独立性。

## 十、A8：联邦互相背书回路

### 危险回路

```text
系统甲引用系统乙
→ 系统乙引用系统丙
→ 系统丙引用系统甲的产品
→ 三方都把另外两方视为独立权威
```

### 断环位置

- 联邦交换保留原始来源与派生链，不只保留最近发送者；
- 对方 Fact 进入本地时仍是有来源的外部主张；
- 信任关系不沿引用链自动传递；
- 无法还原根来源时降低地位或隔离；
- 联邦数量不作为独立证据数量。

### 裁定

联邦边界、证据血缘和本地事实接受权能够断环。

## 十一、单点认知目录

| 单点认知 | 表面上的冗余 | 实际共同根 |
|---|---|---|
| 皇帝唯一世界解释 | 多轮对话和多个任务 | 同一皇帝上下文与偏好 |
| 单一基础模型 | 多个三省六部 Agent | 相同模型族、训练偏差与安全策略 |
| 单一检索入口 | 多个查询 Agent | 相同索引、召回与排序 |
| 单一实体解析 | 多个领域产品 | 相同身份合并错误 |
| 单一知识图谱或当前事实视图 | 多个产品和报告 | 相同被污染的权威读取 |
| 单一本体和解释框架 | 多年版本与多个租户 | 相同分类盲区 |
| 单一评测基准 | 多个候选模型 | 相同优化目标与遗漏 |
| 单一来源家族 | 多个网站和转述 | 相同原始发布者 |
| 单一政策或身份根 | 多区域运行 | 相同错误授权或撤销失败 |
| 单一人类批准者 | 多个 Agent 建议 | 相同认知盲点和责任瓶颈 |

单点认知不等于必须复制所有判断。它表示一旦该认知根错误，所有下游同时失去发现错误的能力。

## 十二、伪多样性

以下数量增长不自动产生认识多样性：

```text
多个 Agent，但使用同一 Prompt 和同一模型
多个模型，但属于同一模型族并共享训练与评测
多个来源，但都转载同一原始消息
多个区域，但共享同一控制根和错误策略
多个审核者，但只看到同一摘要
多个数据库副本，但复制同一错误事实
```

多样性的判断维度至少包括：

- 数据与来源根；
- 模型、训练和能力家族；
- 检索、工具和推理路径；
- 目标、激励和评价标准；
- 组织与权力来源；
- 作用域、辖域和时间；
- 是否能看到原始证据与反证。

## 十三、宏观断环原则

### 13.1 权威来源可追溯

任何批准、事实接受、策略变化和外部行动都能追到不依赖结果自身的权力来源。

### 13.2 挑战路径独立

产生结果的路径不能控制唯一的反证入口、审核标准、审计记录和停止机制。

### 13.3 分歧可持久存在

系统允许候选、争议、少数意见和替代解释保留，不能为了一个“全局唯一答案”过早合并。

### 13.4 现实锚点独立

外部效果、预测评分和业务结果不能只由发出动作或生成预测的主体确认。

### 13.5 确定性边界在 Agent 之外

权限、隔离、审计、版本生效和停止不能依赖相关 Agent 自觉遵守。

### 13.6 按风险购买认知独立性

天机阁不要求每个低风险任务都调用多个模型或 Agent：

```text
低风险、可逆、确定性强
→ 单路径 + Tool 校验 + 可追溯

中风险或开放式判断
→ 反证检查 + 来源差异 + 不确定性表达

高风险、不可逆或跨主权
→ 不共享失败根的验证路径 + 独立审核 + 必要的人类裁定
```

这同时控制 Token 成本，并避免把“节省 Token”变成取消反证。

## 十四、对现有骨架的裁定

本轮发现：

```text
危险循环：8 类
单点认知：10 类
新增一级面：0
新增全局流：0
新增横切维度：0
需要加强的宏观关系：4 类
```

四项加强为：

1. 区分受治理闭环与自证回路；
2. 把系统自身对现实的干预纳入认识血缘；
3. 把认知独立性与失败根记录纳入风险质量判断；
4. 按风险按需启用独立反证，避免常态化多 Agent Token 浪费。

这些分别落入智能治理、证据血缘、风险质量、审计、平台控制和能力演进，不形成新的“认知审计面”。

十面稳定性继续保持。`Skeleton v0.3` 仍未闭合；下一步建立能力演进如何作用于全部架构的全域图。

## 十五、有意不展开

- Agent 投票、辩论或裁判算法；
- 模型多样性与来源独立性评分；
- 具体反证 Prompt、检索路径和评测集；
- 人员双签、审批矩阵与组织编制；
- 知识图谱污染检测和因果推断算法；
- Token 阈值与风险等级参数。
