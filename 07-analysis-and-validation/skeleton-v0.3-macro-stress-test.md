# Skeleton v0.3 第一轮宏观压力测试

状态：Accepted

测试日期：2026-07-24

## 一、测试目标

本轮使用 `Skeleton v0.2` 留下的八个极端场景，同时攻击：

- 十个一级逻辑面；
- 主体生态与分域主权；
- 十种运行形态；
- 七条全局流；
- 作用域、辖域、时间和规模四轴；
- 七个横切治理维度；
- 最低生存内核与八类失效域；
- 负空间和未来替换边界。

测试只寻找宏观断点：

```text
是否出现无人拥有的一级职责？
是否出现无法表达的权力来源？
是否需要一种全新的全局流、坐标轴或横切维度？
是否存在无法隔离、停止、恢复或纠正的失效？
是否有结构只能依靠万能 Agent 才能闭合？
```

本轮不定义场景协议、状态字段、容量数字、恢复步骤或安全算法。

## 二、统一判定标准

每个压力场景回答七个问题：

1. 谁拥有原生权力，谁只有派生权力？
2. 主要由哪些一级面承担责任？
3. 哪些全局流和尺度轴发生冲突？
4. 故障如何跨域传播，在哪里被隔离？
5. 最低生存内核必须保住什么？
6. 错误结果和现实影响如何纠正？
7. 是否形成新的一级结构证据？

结果分为：

```text
Closed
→ 现有宏观结构能够完整承载

Reinforce
→ 不需要新一级结构，但现有不变量或关系必须加强

Gap
→ 出现无法归属的稳定问题族，需要重新评估骨架
```

## 三、P1：跨辖域来源、处理与交付规则冲突

### 压力

公开来源位于区域甲，被研究主体位于区域乙，租户位于区域丙，资料只允许在甲处理，产品却计划交付到丙；三个辖域对保留、解释和删除存在冲突。

### 骨架响应

```text
辖域覆盖层识别多个适用边界
→ 平台控制面执行明确硬约束
→ 刑部提供法规与合规领域分析
→ 智能治理面分离事实冲突、政策冲突与授权冲突
→ 高影响路径在无权威答案时停止
→ 有权人类或外部制度主体裁定
```

- 原生权力：相关法律、监管、权利人与租户合法授权；
- 主要责任：平台控制、智能治理、领域能力、数据底座与产品；
- 主要冲突：授权流、数据流、生命周期和辖域轴；
- 隔离位置：来源准入、处理、存储、产品交付与外部行动边界；
- 最低内核：适用政策版本、资料来源、授权依据、停止与审计。

### 裁定

`Closed`。辖域是横切覆盖层，不是新一级面。详细规则属于后续合规专题。

## 四、P2：外部联邦节点返回污染事实

### 压力

一个已建立合作关系的同行系统返回大量带有完整签名和高置信度的“事实”，其中部分由错误实体合并产生，并开始污染租户研判。

### 骨架响应

```text
联邦身份可信
≠ 对方事实自动可信

外部 Fact
→ 按外部 Claim / Evidence Package 准入
→ 保留来源主权和联邦作用域
→ 本地认知验证、实体消歧与冲突检测
→ 隔离受影响关系、研判和产品
→ 纠正血缘向下游传播
```

- 原生权力：对方仅对其签名和声明负责，不拥有本地事实接受权；
- 主要责任：数据认知、数据底座、智能治理、平台控制；
- 主要冲突：数据流、知识形成流、审计证据流；
- 隔离位置：联邦准入、知识作用域、实体合并与产品发布；
- 最低内核：本地事实标准、来源血缘、受影响范围和撤回能力。

### 裁定

`Reinforce`。不新增联邦面，但固定一条不变量：跨系统交换的是“有来源的主张和证据”，不是无条件继承对方权威。

## 五、P3：热点事件造成全域资源与认知拥塞

### 压力

全球热点同时触发大量采集、关联、研判和告警请求。高热度内容相互复制，低质量来源数量压倒高质量来源，多个租户竞争同一共享能力。

### 骨架响应

```text
热点触发
→ 事件合并与关联范围控制
→ 租户、公平、风险和关键任务优先级共同约束资源
→ Tool 主导高吞吐筛选，Agent 聚焦高价值不确定性
→ 明确降低覆盖、新鲜度或推理深度
→ 质量与证据底线不降级
→ 资源、认知和产品状态分别报告
```

- 原生权力：租户目标不产生独占共享资源的权力；
- 主要责任：平台控制、智能执行、数据认知、研判与产品；
- 主要冲突：预算资源流、数据流、知识流和规模轴；
- 隔离位置：租户、任务、来源、事件簇和能力版本；
- 最低内核：公平策略、关键任务、真实拥塞态势、停止与降级标记。

### 裁定

`Reinforce`。规模轴与预算质量治理足以承载，但必须区分“计算拥塞”和“认知拥塞”：后者是重复、噪声和错误关联淹没有效证据，不只是机器负载。

## 六、P4：区域中断后的最低生存内核运行

### 压力

一个区域同时失去模型服务、部分数据副本和外部网络，但仍有持续任务、待发布高风险告警和人类紧急控制需求。

### 骨架响应

```text
区域真实状态变为 Unknown / Degraded
→ 停止无法证明权限和证据的高影响写入与发布
→ 保留人类控制、政策根、可信权威记录和隔离能力
→ 允许有限只读、缓存事实或人工辅助
→ 恢复后重建数据、权限秩序和执行状态
→ 检查中断期间遗漏、错误和下游影响
```

- 原生权力：区域自治只能使用预先授予的有限权限；
- 主要责任：平台控制、运行、数据底座、交互、治理；
- 主要冲突：控制流、授权流、审计流和辖域/时间轴；
- 隔离位置：区域、租户、任务、能力与产品；
- 最低内核：六类最低能力全部被直接测试。

### 裁定

`Closed`。最低生存内核能够表达区域失效；物理恢复目标属于后续专题。

## 七、P5：来源、Tool 与模型供应链联合污染

### 压力

恶意来源构造内容诱导解析 Tool，Tool 输出又触发模型偏差；多个组件来自同一供应链，却被系统错误当作“独立证据”。

### 骨架响应

```text
多个来源或组件
≠ 多个独立信任根

供应链身份与依赖关系
→ 进入证据、能力和审计血缘
→ 识别共同故障来源与关联失效域
→ 隔离来源、Tool、模型、版本及其派生结果
→ 切换不共享同一失效根的候选能力
→ 纠正事实、产品和演进评测
```

- 原生权力：供应商只声明能力，不拥有事实或生产准入权；
- 主要责任：平台控制、运行、数据认知、数据底座、演进；
- 主要冲突：数据流、知识流、审计流与反馈演进流；
- 隔离位置：来源、能力版本、供应商、任务和知识派生链；
- 最低内核：可信策略根、能力目录、完整依赖血缘和撤销能力。

### 裁定

`Reinforce`。发现一个需要加强的宏观关系：失效域之间可以相关，系统不能用“数量多”推断“相互独立”。该关系落入风险质量、证据血缘、能力目录和审计，不新增横切维度。

## 八、P6：超级模型合并多个治理角色

### 压力

未来超级模型能够在一次推理中完成目标理解、计划、执行选择、证据审核和报告生成，运营者希望删除三省区分以降低成本。

### 骨架响应

```text
一个模型实例
可以承载：规划角色 + 执行建议角色 + 审核角色

但必须保留：
不同授权上下文
不同决定类型
可独立拒绝和封驳
反证来源与接受标准
外部确定性强制点
人类暂停、接管和责任
```

- 原生权力：仍来自人类、平台、租户和 Mission 委托；
- 主要责任：智能治理、运行、平台控制、能力演进；
- 主要冲突：控制流、授权流、知识接受与未来模型代际；
- 隔离位置：角色上下文、决定记录、能力版本和生产发布；
- 最低内核：权力根、停止、审计和真实运行态势。

### 裁定

`Closed`。三省是可区分权力，不是固定三个模型；未来实现可收缩，逻辑制衡不消失。

## 九、P7：外部系统响应成功但现实效果失败

### 压力

天机阁经授权向企业系统发出动作请求，接口返回成功，但现实业务没有发生预期变化，随后告警却被错误解除。

### 骨架响应

```text
Recommendation
≠ Decision
≠ External Command
≠ Acknowledgement
≠ Observed Effect

响应成功
→ 只证明请求被对方接收
→ 通过独立观察确认现实效果
→ 效果未知时保持风险与责任开放
→ 失败时补偿、升级或重新决策
```

- 原生权力：外部行动系统和有权行动责任人；
- 主要责任：治理、运行、产品、数据认知与数据底座；
- 主要冲突：决定授权流、控制流、数据观察流和审计流；
- 隔离位置：动作、外部系统、现实效果与告警状态；
- 最低内核：原决定、命令、回执、观察、责任和停止能力。

### 裁定

`Reinforce`。`Action / Acknowledgement / Effect` 的语义位置必须保留，是否成为独立核心对象留给下一分辨率，不新增外部行动面。

## 十、P8：自我演进改变跨年知识解释

### 压力

新模型和新本体显著改变历史实体关联与趋势解释。新结果更准确，但与数年前已经发布的产品及当时决策依据不一致。

### 骨架响应

```text
能力版本升级
→ 新解释在新知识版本中形成
→ 保留旧能力、旧证据和当时可知结论
→ 区分“历史当时结论”与“当前重新解释”
→ 判断哪些变化属于纠错、哪些属于新视角
→ 必要时更正产品，但不伪造历史
```

- 原生权力：能力演进不能取得改写历史的权力；
- 主要责任：能力演进、数据认知、数据底座、治理和产品；
- 主要冲突：知识流、审计流、反馈演进流与时间轴；
- 隔离位置：能力版本、知识版本、租户产品和历史时期；
- 最低内核：版本、血缘、当时决策依据、当前解释和纠正记录。

### 裁定

`Reinforce`。能力代际必须成为可回放知识的解释上下文；它落入证据血缘、审计、生命周期和演进，不新增“历史解释面”。

## 十一、联合压力结果

| 场景 | 结果 | 一级面变化 | 加强项 |
|---|---|---|---|
| P1 跨辖域冲突 | Closed | 无 | 无新增 |
| P2 联邦事实污染 | Reinforce | 无 | 外部事实降格为有来源主张 |
| P3 全域热点拥塞 | Reinforce | 无 | 区分计算拥塞与认知拥塞 |
| P4 区域中断 | Closed | 无 | 最低生存内核得到验证 |
| P5 联合供应链污染 | Reinforce | 无 | 相关失效域与独立性证据 |
| P6 超级模型合并角色 | Closed | 无 | 物理合并不取消逻辑制衡 |
| P7 响应成功、效果失败 | Reinforce | 无 | Action—Acknowledgement—Effect 分层 |
| P8 演进改变历史解释 | Reinforce | 无 | 能力代际进入可回放解释上下文 |

统计：

```text
Closed：3
Reinforce：5
Gap：0
新增一级面：0
新增全局流：0
新增尺度轴：0
新增横切维度：0
```

## 十二、三项跨场景发现

### 12.1 相关失效关系

失效域不是天然独立。多个来源、模型、Tool、区域或供应商可能共享同一个上游、数据集、模型族、身份系统或治理错误。

```text
多副本 ≠ 独立副本
多来源 ≠ 独立证据
多模型 ≠ 独立判断
多区域 ≠ 独立控制根
```

系统必须能够表达和审计“为什么认为它们独立”。这加强现有证据血缘、能力目录和风险质量，不形成新一级结构。

### 12.2 派生义务与影响传播

数据和结论跨辖域、联邦、产品或外部行动传播时，来源限制、纠正义务、撤回影响和责任不能在复制后消失。

义务不是第八条全局流；它依附于授权、数据、知识、审计和生命周期语义随对象传播。

### 12.3 跨能力代际可回放

长期知识不仅要记录“当时有哪些数据”，还要记录“当时使用了什么能力、规则和解释框架”。否则系统无法解释为什么过去与现在得出不同结论。

这加强时间轴、证据血缘、审计和能力演进之间的连接。

## 十三、第一轮裁定

八个压力场景没有击穿十面，也没有产生新的一级面、全局流、尺度轴或横切维度。

但本轮不能直接宣布 `Skeleton v0.3` 闭合，因为还需要：

1. 把三项加强关系回写到当前架构；
2. 检查全局视图之间的循环权威和单点认知；
3. 建立能力演进作用全域图；
4. 汇总形成可一屏阅读的 v0.3 全景图；
5. 再次执行一级稳定性复核。

当前结论：

```text
Skeleton v0.3 第一轮宏观压力测试：通过
十面稳定性：保持
整体 v0.3：尚未闭合
```

## 十四、有意不展开

- 各压力场景的逐步时序；
- 联邦、外部行动和演进对象 Schema；
- 拥塞、隔离、切换和恢复算法；
- 威胁模型与供应链控制清单；
- 模型独立性和证据独立性的量化方法；
- 具体法规、容量、部署和产品规则。
