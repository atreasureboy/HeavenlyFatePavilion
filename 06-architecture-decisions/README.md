# 架构决策

状态：Reference

这里保存架构决策记录（ADR）。ADR 回答“为什么这样设计”，而不是重复当前架构。

每份 ADR 至少包含背景、驱动因素、候选方案、最终决定、正负影响、风险、重新评估条件及关联场景。

ADR 一经接受不直接改写；需要改变决定时，创建新的 ADR 并将旧 ADR 标记为 `Superseded`。
