# SCN-0006：长时任务权限撤销

状态：Accepted

## 目标

一项长时私有调查运行期间，仙人的项目角色被管理员撤销。验证权限不是 Run 启动时的一次性检查。

## 主路径

```text
平台控制面提交角色/授权变更
→ 发布新的 policy_set_version 与 Revocation Event
→ 运行面定位持有相关委托和能力令牌的 Run / Task / Agent
→ 阻止新的 Task 和副作用
→ Agent/Tool/数据访问在下一强制点重新判定
→ 受影响 Task 进入 Paused / Cancelled
→ 撤销临时凭证，隔离临时文件和未发布结果
→ 已发生外部副作用进入补偿评估
→ Mission 交智能治理面决定：
   ├── 换有权负责人继续
   ├── 缩小到仍授权范围
   └── 取消并按生命周期处置
→ 通知有权主体，不向被撤权用户泄露新增状态
```

## 数据处置

- 已合法形成的事实不因用户撤权自动删除；
- 被撤权用户不能继续读取任务历史和产品；
- 用户个人工作区材料按所有权与保留策略决定迁移、冻结或删除；
- 审计保留撤销前后的访问和决定，但同样受最小访问控制。

## 异常

- Agent 离线未接收撤销事件：下一次 Tool、数据或模型调用由强制点拒绝；
- 缓存仍含旧许可结果：策略版本进入缓存 Key 并使其失效；
- 已排队产品即将分发：产品分发点重新授权并阻断；
- 不可逆外部动作已完成：不能伪称回滚，记录并进入人工补偿。

## 验证结果

通过。确定性强制点兜住了 Agent 和异步消息延迟；授权撤销改变未来使用权，不抹除审计历史。

验证 `INV-0002`、`INV-0006`、`INV-0007`、`INV-0008`。
