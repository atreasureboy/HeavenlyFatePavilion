# SCN-0001：公共信息快速查询

状态：Accepted

## 目标

仙人询问“快速概览某家公开公司最近发生了什么”。验证低风险、已有公共事实的任务能够节省 Token，同时不牺牲作用域、证据和审计。

## 参与者与前置上下文

- 仙人、皇帝交互投影；
- 人机交互、智能治理、数据底座、情报产品面；
- 按需使用数据认知和情报研判；
- `Public Scope`、R0、Overview 证据档位、有限预算。

## 主路径

```text
仙人提问
→ 入口绑定租户和主体，但查询数据范围为显式 Public Scope
→ 皇帝识别为低风险概览 Intent
→ 治理规则创建轻量 Mission，不启动完整三省审议
→ 数据底座按权限查询公共 Entity / Event / Change / Fact
→ 确定性服务检查新鲜度、引用和缓存策略
→ 若已有 Assessment 仍有效则复用，否则按需调用轻量研判
→ 产品模板形成带引用的概览
→ 皇帝解释结果、时间范围和未知项
→ 写入查询、引用、预算与交付记录
```

状态变化：

```text
Mission Draft → Approved → Active → Completed
Run Created → Validated → Running → Succeeded
Product Draft → Approved → Published
```

## Agent / Tool 分工

- 皇帝：意图解释与最终交互；
- 治理规则：风险分级和简化路径选择；
- 检索、权限过滤、新鲜度检查、模板与引用展开：Tool；
- 只有存在新变化或歧义时才启动研判 Agent。

## 横切验证

- 多租户：公共作用域显式表示，查询历史仍属于当前租户；
- 权限：公共可读不等于无身份调用；
- 证据：Overview 可展示未完全验证信息，但必须标记；
- 预算：优先缓存和既有事实；
- 质量：过期内容触发补查，不以旧缓存伪装实时；
- 审计：记录使用了哪些事实版本；
- 生命周期：会话、缓存和产品各按自身策略保留。

## 异常

- 实体同名无法消歧：返回澄清问题；
- 公共事实已过期：创建补充认知 Task；
- 预算不足以完成补查：返回带时效声明的 `Degraded` 结果；
- 引用进入争议：产品不得继续显示为确定事实。

## 验证结果

通过。证明“少用 Agent”是治理路径选择，不是省略权限、证据和审计。

验证 `INV-0001`、`INV-0003`、`INV-0004`、`INV-0008`。
